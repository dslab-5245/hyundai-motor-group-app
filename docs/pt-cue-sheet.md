# 2차 PT 라이브 큐시트 (에뮬레이터 + Virtual Console, 약 4분)

사전 준비: 에뮬레이터 `pleos_connect` 콜드 부팅 → 앱 설치 → 작곡실에서 장르 로파이·강도 보통 확인 → 데모 시나리오 **끄기**(라이브 조작) 또는 **켜기**(스토리 자동 재생, 106초).

| # | 조작 (Virtual Console) | 들리는 것 | 화면 | 말할 것 |
|---|---|---|---|---|
| 1 | 앱 실행 → 작곡실 → 연주 시작, Gear **D** | 2마디 인트로 뒤 드럼 인 | 흐름 링 60% | "시동을 걸면 이 길의 테마로 시작합니다" |
| 2 | Steering ±30° 천천히 | 멜로디가 좌우로 따라옴 | 링 상승 | "조향은 패닝입니다" |
| 3 | Turn signal **L** → Steering 160° 2초 유지 | 림 클릭, 레이어 하나 즉시 열림 | "깜빡이 켜고 회전" | "깜빡이는 즉시 보상" |
| 4 | 30초 가만히 | 베이스·패드·멜로디 차례로 | 링 90%+ | "좋은 운전은 천천히 쌓입니다(5초 상승)" |
| 5 | Steering 급스윕 1회 + Brake 짧게 | 잠깐 숨 고르기 뒤 복귀 | "긴급 회피로 봤어요" | "30초 무사고 뒤 첫 급조작은 회피로 봅니다 — 감점 절반" |
| 6 | 20초 뒤 Brake **3회 연타** | 0.12초 안에 어둡고 작아짐 | 링 주황, "브레이크 반복" | "습관은 바로 들립니다. 끊기진 않습니다(바닥 0.1)" |
| 7 | 5초 가만히 | 레이어가 하나씩 돌아옴 | 링 녹색 | "회복은 5초" |
| 8 | Wiper **ON**, Cruise **ON** | 비 텍스처·셰이커, 드론 | "비", "크루즈" | "맥락은 질감이 됩니다" |
| 9 | 터미널: `adb shell am startservice -n io.drivesymphony.app/.audio.SymphonyService -a setGenre --es ACTION_PARAM '{"genre":"JAZZ"}'` | 다음 마디에서 재즈 트리오 | 장르 칩 | "Gleo 음성 명령 4종 스키마" |
| 10 | Gear **P** | 마무리 1마디, 리버브로 사라짐 | 여정의 곡 카드 → 공유 | "오늘 당신이 연주한 곡" |

데모 시나리오를 켠 경우(자동): 0–20 s 시내 → 20–28 s 습관적 급조작 → 44 s까지 회복 → 고속 크루즈 만개 → **86 s 긴급 회피 1회(숨만 고름)** → 90–98 s 비 → 99 s 제동 → 103 s P. 타임라인 수치는 `previews/story_flow_timeline.tsv`.

예상 질문과 답:
- "끼어들기 회피도 벌주나?" → 아니요. 30초 무사고 뒤 첫 급조작과 그 뒤 2.5초는 한 묶음으로 감점 절반·펄스 절반(측정 최저 flow 0.81, 같은 조작이 습관일 때 0.61).
- "차속이 없는데 과속은?" → 내비 위치 4초 창 추정(σ=3 m에서 RMS 1.8 km/h) + 2초 지속 규칙 + 내비 카메라 알림 즉시. 핵심 채점은 조향·브레이크·깜빡이.
- "폰으로도 되지 않나?" → 핸들 각속도·페달 on/off 횟수·깜빡이·벨트·와이퍼는 차량 신호뿐.
- "질리지 않나?" → 매 여정 생성, 같은 길은 같은 테마, 8마디 A-A-B-A·모티프 응답·휴머나이즈. 30곡 고갈로 끝난 선례와 다름.
- "CPU?" → 데스크톱 JVM 단일 코어 1.0~1.3%(40개 테스트 중 성능 테스트가 매번 측정). 차량에서 4%를 3초 넘기면 라이트 프로파일(리버브 1채널 공유·더블러 생략)로 자동 전환, 작곡실 '오디오 부하' 행에 표시. 차량 실측은 스모크 로그.
